Changelog

What shipped, when. We deploy continuously — notable changes are listed here.

October 21, 2026

Try it without signing up

  • Public trial scans: paste any public GitHub repo URL at braimsec.world/trial — no account needed.
  • Trial API for developers: POST /api/trial/scans (see Docs).
  • Cleaner trial summaries: duplicate rule-family findings on the same line are merged, with the top 5 shown by severity.
  • Site refresh: official launch polish across braimsec.world.
October 20, 2026

Email notifications

  • Transactional email is live: scan-failure alerts and trial notifications via support@braimsec.world.
  • Nightly backups verified with a successful restore test.
  • Interactive API reference at api.braimsec.world/docs with strict documentation linting.
October 5, 2026

Crypto payments

  • Pay with USDT (BNB Smart Chain) via NOWPayments — hosted invoice, automatic plan activation on confirmation.
  • Checkout page with plan and billing-cycle selection.
October 2, 2026

Infrastructure hardening

  • Production moved to dedicated VPS infrastructure.
  • Scan runner isolated behind a scan-only API — the worker no longer touches Docker directly.
  • Uptime monitoring every 15 minutes with automatic service recovery.
October 1, 2026

Whish payments for Lebanon

  • Customers in Lebanon can pay manually with Whish — no card needed. See pricing.
  • support@braimsec.world email forwarding activated.
September 26, 2026

Public launch

  • braimsec.world goes live: product pages, pricing, terms, privacy, and refund policy.
  • Subscription billing with Starter, Pro, and Advanced plans; 7-day free trial on every plan.
  • Core scanning: Python and JavaScript/TypeScript, deterministic engine plus AI triage, SARIF export.
